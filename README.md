# 💱 幣值轉換器 FX PRO (Currency Converter)

> 一個現代化、響應式且支援即時匯率計算與歷史趨勢圖表的前端單頁 Web 應用程式 (SPA)。

點擊體驗：[https://clairemartin1112.github.io/currency-converter/](https://clairemartin1112.github.io/currency-converter/)

---

## ✨ 核心特色 (Key Features)

- ⚡ **即時國際匯率**：自動連接公開匯率 API (`open.er-api.com`) 獲取最新國際數據。
- 🔄 **雙向對換與一鍵 Swap**：支援輸入任意金額，提供滑順動態旋轉的一鍵對調幣別按鈕。
- 📊 **歷史匯率走勢圖**：使用原生 HTML5 Canvas 渲染 7 天 / 30 天 / 90 天走勢波幅與最高/最低/平均價分析。
- 🌍 **多幣別對照矩陣**：可一次檢視並比較多種世界主要貨幣（TWD, USD, JPY, EUR, GBP, KRW, HKD, AUD, THB 等）。
- ⭐ **常用幣別收藏與搜尋**：可收藏常用幣別，並支援依據代碼與中文名稱（如 台幣, 日圓）搜尋選單。
- 🌙 **深淺色主題與離線快取**：支援一鍵切換 Dark / Light Mode，自動快取數據於 `localStorage`，無網路亦可使用。

---

## 🛠️ 使用技術 (Tech Stack)

- **HTML5 & CSS3**：語義化標籤、CSS Variables 變數系統、Modern Glassmorphism (玻璃擬態效果)。
- **Vanilla JavaScript (ES6+)**：模組化狀態管理、`fetch` API 數據存取、原生 Canvas 繪圖。
- **FontAwesome & Google Fonts**：Outfit & Inter 質感字體與現代化 Icon 圖標庫。
